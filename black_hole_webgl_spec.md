# Техническое задание: полноэкранная 3D-заставка «Black Hole»

## 1. Цель проекта

Разработать полноэкранную анимированную WebGL-заставку для браузера на основе визуальной концепции чёрной дыры с аккреционным диском.

Заставка должна создавать кинематографичный эффект глубокого космоса: массивная чёрная дыра находится под углом к камере, вокруг неё медленно вращается светящийся аккреционный диск, а область вокруг горизонта событий дополнительно подчёркивается эффектом гравитационного линзирования.

Основной принцип: **минималистичная, тёмная, объёмная и гипнотическая сцена без интерфейсных элементов**.

---

## 2. Референс

Исходный визуальный референс:

`https://i.3dmodels.org/uploads/monarch/003_Animated_Black_Hole/Animated_Black_Hole_1000_0001.jpg`

Дополнительная концептуальная ссылка:

`https://3dmodels.org/ro/3d-models/animated-black-hole/`

Референс следует использовать как ориентир по композиции, форме аккреционного диска, освещению и общему кинематографическому настроению.

Не требуется буквально копировать изображение. Цель — создать самостоятельную WebGL-реализацию с аналогичной визуальной идеей.

## 3. Общая композиция

Сцена должна занимать весь экран браузера.

### Viewport

- ширина: `100vw`;
- высота: `100vh`;
- Canvas: `position: fixed`;
- отсутствие внешних отступов;
- отсутствие scrollbar;
- изображение должно выходить от края до края окна;
- адаптация к изменению размера окна;
- поддержка desktop и mobile.

Пример базовой структуры:

```text
Browser viewport
┌──────────────────────────────────────────────┐
│                                              │
│                 космическое                  │
```

На мобильных устройствах масштаб должен автоматически корректироваться.

## 4. Чёрная дыра

В центре сцены располагается сферическая область, представляющая горизонт событий.

### Требования

- поверхность визуально абсолютно чёрная;
- отсутствуют обычные детали поверхности;
- объект не должен выглядеть как планета;
- граница горизонта событий должна быть подчеркнута окружающим свечением;
- вокруг центральной области должен присутствовать тонкий светящийся photon ring;
- центральная область должна сохранять практически абсолютную темноту даже при сильном свечении диска.

Не рекомендуется использовать только простой:

```js
THREE.Mesh(
    new THREE.SphereGeometry(),
    new THREE.MeshBasicMaterial({ color: 0x000000 })
)
```

Необходимо дополнительно использовать shader/post-processing для создания визуальной глубины.

---

## 5. Аккреционный диск

Главный визуальный элемент — раскалённый аккреционный диск.

Диск должен располагаться вокруг чёрной дыры и быть наклонён относительно камеры.

### Геометрия

Предпочтительный вариант:

- кольцевой диск;
- несколько концентрических слоёв;
- частицы плазмы;
- процедурный шум;
- shader-based deformation;
- отсутствие идеально ровной геометрии.

Диск не должен выглядеть как плоское металлическое кольцо.

Он должен напоминать:

> поток раскалённой плазмы, вращающийся вокруг массивного гравитационного объекта.

---

## 6. Угол камеры

Камера не должна смотреть прямо на диск.

Рекомендуемый угол:

```text
20–35 градусов
```

относительно плоскости аккреционного диска.

Например:

```js
camera.position.set(0, 2.8, 5.5);
camera.lookAt(0, 0, 0);
```

Точные значения необходимо подбирать визуально.

Наклон должен быть достаточно заметным, чтобы:

- диск воспринимался как эллипс;
- была видна его толщина;
- задняя часть диска могла визуально проходить вокруг чёрной дыры;
- сцена воспринималась объёмной.

---

## 7. Гравитационное линзирование

Это один из главных эффектов сцены.

Задняя часть аккреционного диска должна визуально изгибаться вокруг чёрной дыры.

Условная композиция:

```text
             задняя часть диска
                  ╭──────╮
             ╭────╯      ╰────╮
           ╱                    ╲
          │       ███████        │
          │      █████████       │
          │      █ BLACK █       │
          │      █  HOLE █       │
          │      █████████       │
           ╲                    ╱
             ╰────────────────╯
```

Для реализации можно использовать:

1. screen-space distortion;
2. GLSL fragment shader;
3. ray-marching;
4. математическое искажение координат;
5. комбинацию нескольких методов.

Для первой версии допускается приближённое визуальное моделирование, если оно обеспечивает убедительный результат при высокой производительности.

## 8. Цветовая палитра

Основная цветовая схема:

### Центр

```text
#000000
```

### Внутренний диск

От:

```text
#FFFFFF
```

до:

```text

```

### Средняя часть

```text

```

### Внешняя область

```text
#E85D04
```

и тёмно-красные оттенки.

Цвета не должны выглядеть как плоская градиентная полоска.

Необходимо использовать:

- noise;
- brightness variation;
- emissive intensity;
- turbulence;
- alpha variation.

## 9. Свечение

Добавить кинематографичный Bloom.

Рекомендуемый стек:

```text
Three.js
EffectComposer
RenderPass
UnrealBloomPass
```

Bloom должен быть заметен вокруг наиболее ярких областей, но не должен превращать всю сцену в размытое светящееся пятно.

Особое внимание:

- центральное кольцо — сильное свечение;
- внутренняя плазма — сильное;
- внешняя область — умеренное;
- звёзды — минимальное.

---

## 10. Анимация

Основное движение — очень медленное вращение.

### Аккреционный диск

Диск вращается вокруг центральной оси.

Рекомендуемая скорость:

```js
rotationSpeed = 0.001–0.004;
```

Значение должно восприниматься как медленное.

Не использовать резкое вращение.

### Дифференциальное вращение

Внутренние области должны вращаться быстрее внешних.

Условно:

```text
inner radius → fast
middle radius → medium
outer radius → slow
```

Это создаёт ощущение динамической плазмы.

---

## 11. Движение плазмы

Плазма должна двигаться не только по окружности.

Рекомендуется добавить:

- procedural noise;
- turbulence;
- небольшие радиальные смещения;
- изменение brightness;
- изменение opacity;
- отдельные горячие участки.

Пример концепции:

```js
angle += speed * delta;
radius += noise(angle, time) * distortion;
brightness = noise(angle, radius, time);
```

---

## 12. Камера

Камера должна оставаться преимущественно статичной.

Допускается очень медленное движение:

- небольшое orbit motion;
- микроскопическое изменение позиции;
- лёгкий parallax.

Амплитуда движения:

```text
2–5 градусов
```

за длительный промежуток времени.

Камера не должна постоянно заметно вращаться вокруг объекта.

Цель — ощущение живого пространства, а не демонстрация 3D-модели.

---

## 13. Космический фон

Фон:

- почти чёрный;
- очень тёмный сине-чёрный градиент;
- небольшое количество звёзд;
- отсутствие туманностей, планет и других крупных объектов.

Звёзды:

- очень маленькие;
- разная яркость;
- случайное расположение;
- большая глубина;
- некоторые звёзды могут слегка мерцать.

Пример:

```text
background:
    #000000
        ↓
    #02050A
        ↓
    #030711
```

## 17. Производительность

Основной приоритет — плавная анимация.

Целевой FPS:

```text
Desktop: 60 FPS
Mobile:  30–60 FPS
```

Необходимо:

- использовать `requestAnimationFrame`;
- избегать создания объектов внутри animation loop;
- использовать `BufferGeometry`;
- использовать shaders вместо большого количества CPU-операций;
- ограничивать количество particles на слабых устройствах;
- корректно освобождать GPU resources;
- адаптировать pixel ratio.

Рекомендуемый код:

```js
renderer.setPixelRatio(
    Math.min(window.devicePixelRatio, 2)
);
```

На мобильных можно дополнительно ограничить:

```js
Math.min(window.devicePixelRatio, 1.5)
```

## 24. Accessibility

Несмотря на декоративный характер заставки:

- Canvas не должен блокировать управление страницей, если поверх него появится интерфейс;
- желательно предусмотреть отключение анимации через `prefers-reduced-motion`;
- не использовать вспышки высокой частоты.

Пример:

```css
@media (prefers-reduced-motion: reduce) {
    /* уменьшить скорость анимации */
}
```

## 25. Fallback

Если WebGL2 недоступен:

1. попробовать WebGL;
2. если WebGL недоступен — показать статичный фон;
3. не показывать пустую страницу.

Пример:

```text
WebGL2
   ↓
WebGL
   ↓
Static fallback
```

## 28. Критерий конечного результата

Итоговая заставка должна восприниматься не как вращающийся 3D-объект, а как **живое космическое явление**.

При первом взгляде пользователь должен видеть:

> глубокий чёрный космос → яркий искривлённый аккреционный диск → абсолютно тёмную чёрную дыру → медленное движение плазмы → объём и глубину пространства.

Анимация должна быть достаточно медленной, чтобы её можно было использовать как постоянный фон/заставку сайта, но при этом сцена не должна выглядеть статичной.

Главный визуальный приоритет:

```text
BLACK HOLE
     ↓
GRAVITATIONAL LENSING
     ↓
GLOWING ACCRETION DISK
     ↓
SLOW ROTATION
     ↓
DEEP SPACE
```

## 29. Итоговая формулировка для AI-кодера

> Создай production-ready полноэкранную WebGL-заставку на HTML/JavaScript/Three.js. В центре находится реалистичная чёрная дыра с абсолютно тёмным горизонтом событий и ярким аккреционным диском. Камера смотрит на систему под углом 20–35 градусов. Аккреционный диск должен выглядеть как раскалённая плазма, а не как плоское кольцо. Реализуй процедурное движение плазмы, дифференциальное вращение и визуальную имитацию гравитационного линзирования, при которой задняя часть диска изгибается вокруг чёрной дыры. Используй GLSL shaders, WebGL2, particles, EffectComposer и UnrealBloomPass. Добавь минималистичное звёздное поле и глубокий чёрно-синий космический фон. Вся сцена должна занимать 100vw × 100vh без scrollbar. Анимация должна быть медленной, плавной и кинематографичной. Реализуй responsive behavior, resize handling, devicePixelRatio optimization, mobile performance и prefers-reduced-motion. Код должен быть модульным, понятным и готовым для дальнейшей разработки.
